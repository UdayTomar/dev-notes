# 10 — CSS quick revision

## Definitions
- CSS: stylesheet language for presentation and layout.
- Selector: pattern that selects elements.
- Specificity: part of the cascade used to resolve competing declarations.
- Box model: content, padding, border, margin.
- Flexbox: one-dimensional layout.
- Grid: two-dimensional layout.
- Media query: applies styles conditionally.

## Important properties
`color`, `background`, `font-family`, `font-size`, `margin`, `padding`, `border`, `width`, `max-width`, `display`, `position`, `gap`, `flex`, `grid-template-columns`, `overflow`, `z-index`.
