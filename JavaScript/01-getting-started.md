# 01 — Getting started

JavaScript is a programming language used in browsers and environments such as Node.js.

## Add JavaScript to HTML

```html
<script src="script.js" defer></script>
```

`defer` downloads the script while HTML is parsed and executes it after parsing.

## First program

```javascript
console.log("Hello, world!");
```

Output in the developer console:

```text
Hello, world!
```

## Comments

```javascript
// Single-line comment

/*
  Multi-line comment
*/
```

## Developer tools
- Console: inspect logs and errors.
- Elements: inspect the DOM.
- Sources: debug scripts.
- Network: inspect requests and responses.

## Practice
Create `index.html` and `script.js`, link the script with `defer`, and log a greeting.
