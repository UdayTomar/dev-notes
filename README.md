## About

Dev Notes is a public-friendly learning repository maintained by **Uday Tomar**. It collects explanations, syntax references, examples, outputs, common mistakes, and practice prompts for web development and programming.

| Track | Focus |

| [CSS](CSS/README.md) | Selectors, cascade, box model, layout, responsive design |
| [Python](Python/README.md) | Fundamentals, collections, functions, files, exceptions, OOP |
| [JavaScript](JavaScript/README.md) | Language basics, DOM, events, asynchronous code, modules |

## How to use

1. Open a language index.
2. Study one topic and type the examples yourself.
3. Change the code and predict the result.
4. Complete the practice prompts without copying.
5. Add your own examples and exam reminders.

These are learning notes, not a replacement for official documentation. If you find an error, open an issue or pull request with the page, section, and a reproducible correction. Check [official resources](Resources/useful-links.md) for current behavior.
