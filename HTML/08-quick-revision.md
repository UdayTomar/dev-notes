# 08 — HTML quick revision

## Definitions
- HTML: markup language for structuring web content.
- Element: a unit of HTML markup.
- Attribute: additional information in a start tag.
- DOM: object representation of a document.
- Semantic HTML: elements that communicate content meaning.
- `alt`: text alternative for an image.
- `href`: link destination.
- `src`: source for embedded content.

## Common tags

| Tag | Purpose |
|---|---|
| `h1`–`h6` | Headings |
| `p` | Paragraph |
| `a` | Link |
| `img` | Image |
| `ul`, `ol`, `li` | Lists |
| `table`, `tr`, `th`, `td` | Tabular data |
| `form`, `input`, `label` | Forms |
| `button` | Action |
| `header`, `nav`, `main`, `footer` | Semantic regions |
